# React Activity Portal — Stacked Edition

A single responsive React application containing five practical activities:

This edition uses a different stacked page structure, a two-level header, and a full-width activity dashboard while preserving the assessment requirements and logic.

1. Login Authentication
2. Student Grade Evaluation
3. Password Strength Checker
4. Electricity Bill Calculator
5. Employee Attendance Checker

## Run the project

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build for production

```bash
npm run build
```
